One last setup step

Curium DNS is running. Cloudflare Turnstile protection is prepared in the app, but the widget keys have not been added to the Render environment yet.

  1. Open the Cloudflare Turnstile dashboard and create a widget.
  2. Add curium-dns-app.onrender.com to the widget’s allowed hostnames.
  3. In Render → Curium-DNS-App → Environment, add TURNSTILE_SITE_KEY and TURNSTILE_SECRET_KEY.
  4. Save changes. Render will redeploy, and the Turnstile check will appear automatically.

The secret key must only be stored in Render environment variables. Do not put it in GitHub or in the page source.

The DNS-over-HTTPS endpoint remains separate so standard DNS clients can use it without an interactive browser challenge.
