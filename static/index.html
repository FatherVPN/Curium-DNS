The essentials for a DNS-over-HTTPS gateway, without a dashboard full of noise.

Encrypted DNS requests

DNS messages are sent to this gateway over HTTPS instead of plain-text DNS transport.

DNS-only forwarding

The API accepts DNS wire-format queries only and forwards them to the configured upstream resolver.

Abuse safeguards

Request-size checks, standard-query validation, timeouts, and a lightweight per-IP rate limit.

Quick setup

Bring Curium to your browser.

Use the endpoint below in a browser that supports a custom DNS-over-HTTPS provider. The setting is usually called “Secure DNS” or “DNS over HTTPS”.

Chrome or Microsoft Edge

Verify the connection

Reload this page and check the resolver status above. A live status confirms the gateway process is responding.

Device note: Android’s “Private DNS” setting expects DNS-over-TLS, and iOS manual Wi-Fi DNS expects IP addresses. They do not accept a DoH URL directly. Use a compatible browser or a separate DoH profile/app for system-wide DNS.

Bring Curium to Windows.

Use this endpoint as a custom Secure DNS provider in a browser on Windows 10 or 11. The same address works in Edge, Chrome and Firefox.

i
Want to use Curium for all Windows apps?

Windows’ built-in system DoH setup requires a DNS server IP address as well as a DoH template. This Render web service currently exposes an HTTPS app endpoint, not a dedicated static DNS-server IP or a UDP/TCP port 53 listener. So the URL above works in DoH-capable browsers, but cannot honestly be advertised as a system-wide Windows DNS address yet. For system-wide setup, Curium needs a DNS front end on a server with a stable public IP.

Know what DNS can and cannot do.

Clear boundaries make for a more trustworthy service.

What it helps with

Encrypting DNS queries between a compatible client and this HTTPS endpoint, and forwarding supported DNS questions to Cloudflare DNS.

What it does not do

It is not a VPN or traffic proxy. It does not change your public IP, defeat IP/SNI/DPI filtering, or override a service’s regional availability rules.
